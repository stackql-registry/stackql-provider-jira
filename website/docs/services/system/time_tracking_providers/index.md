## `SELECT` examples

<Tabs
    defaultValue="list"

<TabItem value="list">

Returns all time tracking providers. By default, Jira only has one time tracking provider: *JIRA provided time tracking*. However, you can install other time tracking providers via apps from the Atlassian Marketplace. For more information on time tracking providers, see the documentation for the &#91; Time Tracking Provider&#93;(https:​//developer.atlassian.com/cloud/jira/platform/modules/time-tracking-provider/) module.&lt;br /&gt;&lt;br /&gt;**&#91;Permissions&#93;(#permissions) required:** *Administer Jira* &#91;global permission&#93;(https:​//confluence.atlassian.com/x/x4dKLg).

```sql
SELECT
name,
key,
url
FROM jira.system.time_tracking_providers
WHERE cloud_id = '{{ cloud_id }}' -- required unless ATLASSIAN_CLOUD_ID is set
;
```
