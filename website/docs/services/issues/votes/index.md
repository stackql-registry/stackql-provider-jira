## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="list">

Returns details about the votes on an issue.&lt;br /&gt;&lt;br /&gt;This operation requires the **Allow users to vote on issues** option to be *ON*. This option is set in General configuration for Jira. See &#91;Configuring Jira application options&#93;(https:​//confluence.atlassian.com/x/uYXKM) for details.&lt;br /&gt;&lt;br /&gt;This operation can be accessed anonymously.&lt;br /&gt;&lt;br /&gt;**&#91;Permissions&#93;(#permissions) required:**&lt;br /&gt;&lt;br /&gt; *  *Browse projects* &#91;project permission&#93;(https:​//confluence.atlassian.com/x/yodKLg) for the project that the issue is ini&lt;br /&gt; *  If &#91;issue-level security&#93;(https:​//confluence.atlassian.com/x/J4lKLg) is configured, issue-level security permission to view the issue.&lt;br /&gt;&lt;br /&gt;Note that users with the necessary permissions for this operation but without the *View voters and watchers* project permissions are not returned details in the `voters` field.

```sql
SELECT
name,
account_id,
display_name,
account_type,
active,
app_type,
application_roles,
avatar_urls,
email_address,
groups,
guest,
key,
locale,
self,
time_zone
FROM jira.issues.votes
WHERE issue_id_or_key = '{{ issue_id_or_key }}' -- required
AND cloud_id = '{{ cloud_id }}' -- required unless ATLASSIAN_CLOUD_ID is set
;
```
</TabItem>
</Tabs>

```sql
INSERT INTO jira.issues.votes (
issue_id_or_key,
cloud_id

'{{ cloud_id }}'
;
```

Deletes a user's vote from an issue. This is the equivalent of the user clicking *Unvote* on an issue in Jira.&lt;br /&gt;&lt;br /&gt;This operation requires the **Allow users to vote on issues** option to be *ON*. This option is set in General configuration for Jira. See &#91;Configuring Jira application options&#93;(https:​//confluence.atlassian.com/x/uYXKM) for details.&lt;br /&gt;&lt;br /&gt;**&#91;Permissions&#93;(#permissions) required:**&lt;br /&gt;&lt;br /&gt; *  *Browse projects* &#91;project permission&#93;(https:​//confluence.atlassian.com/x/yodKLg) for the project that the issue is in.&lt;br /&gt; *  If &#91;issue-level security&#93;(https:​//confluence.atlassian.com/x/J4lKLg) is configured, issue-level security permission to view the issue.

```sql
DELETE FROM jira.issues.votes
WHERE issue_id_or_key = '{{ issue_id_or_key }}' --required
AND cloud_id = '{{ cloud_id }}' --required unless ATLASSIAN_CLOUD_ID is set
;
```
