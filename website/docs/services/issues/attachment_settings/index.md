<Tabs

<TabItem value="get">

Returns the attachment settings, that is, whether attachments are enabled and the maximum attachment size allowed.&lt;br /&gt;&lt;br /&gt;Note that there are also &#91;project permissions&#93;(https:​//confluence.atlassian.com/x/yodKLg) that restrict whether users can create and delete attachments.&lt;br /&gt;&lt;br /&gt;This operation can be accessed anonymously.&lt;br /&gt;&lt;br /&gt;**&#91;Permissions&#93;(#permissions) required:** None.

```sql
SELECT
enabled,
upload_limit
FROM jira.issues.attachment_settings
WHERE cloud_id = '{{ cloud_id }}' -- required unless ATLASSIAN_CLOUD_ID is set
;
```
