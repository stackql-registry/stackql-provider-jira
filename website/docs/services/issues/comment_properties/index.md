## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the value of a comment property.&lt;br /&gt;&lt;br /&gt;This operation can be accessed anonymously.&lt;br /&gt;&lt;br /&gt;**&#91;Permissions&#93;(#permissions) required:**&lt;br /&gt;&lt;br /&gt; *  *Browse projects* &#91;project permission&#93;(https:​//confluence.atlassian.com/x/yodKLg) for the project.&lt;br /&gt; *  If &#91;issue-level security&#93;(https:​//confluence.atlassian.com/x/J4lKLg) is configured, issue-level security permission to view the issue.&lt;br /&gt; *  If the comment has visibility restrictions, belongs to the group or has the role visibility is restricted to.

```sql
SELECT
key,
value
FROM jira.issues.comment_properties
WHERE comment_id = '{{ comment_id }}' -- required
AND property_key = '{{ property_key }}' -- required
AND cloud_id = '{{ cloud_id }}' -- required unless ATLASSIAN_CLOUD_ID is set
;
```
</TabItem>

## `UPDATE` examples

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}

<TabItem value="update">

Creates or updates the value of a property for a comment. Use this resource to store custom data against a comment.&lt;br /&gt;&lt;br /&gt;The value of the request body must be a &#91;valid&#93;(http:​//tools.ietf.org/html/rfc4627), non-empty JSON blob. The maximum length is 32768 characters.&lt;br /&gt;&lt;br /&gt;**&#91;Permissions&#93;(#permissions) required:** either of:&lt;br /&gt;&lt;br /&gt; *  *Edit All Comments* &#91;project permission&#93;(https:​//confluence.atlassian.com/x/yodKLg) to create or update the value of a property on any comment.&lt;br /&gt; *  *Edit Own Comments* &#91;project permission&#93;(https:​//confluence.atlassian.com/x/yodKLg) to create or update the value of a property on a comment created by the user.

```sql
UPDATE jira.issues.comment_properties
SET 
value = '{{ value }}'
WHERE 
comment_id = '{{ comment_id }}' --required
AND property_key = '{{ property_key }}' --required
AND cloud_id = '{{ cloud_id }}' --required unless ATLASSIAN_CLOUD_ID is set
AND value = '{{ value }}' --required;
```
</TabItem>
