## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[

Returns details for the current user.&lt;br /&gt;&lt;br /&gt;**&#91;Permissions&#93;(#permissions) required:** Permission to access Jira.

```sql
SELECT
name,
account_id,
display_name,
account_type,
active,
app_type,
application_roles,
avatar_urls,
email_address,
groups,
guest,
key,
locale,
self,
time_zone
FROM jira.users.myself
WHERE cloud_id = '{{ cloud_id }}' -- required unless ATLASSIAN_CLOUD_ID is set
AND expand = '{{ expand }}'
;
```
