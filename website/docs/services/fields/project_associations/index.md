Returns a &#91;paginated&#93;(#pagination) list of project associations for the given custom field. Each association contains the ID of a project the field is associated with.&lt;br /&gt;&lt;br /&gt;**&#91;Permissions&#93;(#permissions) required:** *Administer Jira* &#91;global permission&#93;(https:​//confluence.atlassian.com/x/x4dKLg).

```sql
SELECT
project_id
FROM jira.fields.project_associations
WHERE field_id = '{{ field_id }}' -- required
AND cloud_id = '{{ cloud_id }}' -- required unless ATLASSIAN_CLOUD_ID is set
AND start_at = '{{ start_at }}'
AND max_results = '{{ max_results }}'
;
```
