## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Returns the quick filter for a given quick filter ID. The quick filter will only be returned if the user can view the board that the quick filter belongs to.

```sql
SELECT
id,
name,
board_id,
description,
jql,
position
FROM jira.agile.board_quick_filters
WHERE board_id = '{{ board_id }}' -- required
AND quick_filter_id = '{{ quick_filter_id }}' -- required
AND cloud_id = '{{ cloud_id }}' -- required unless ATLASSIAN_CLOUD_ID is set
;
```
</TabItem>
<TabItem value="list">

Returns all quick filters from a board, for a given board ID.

```sql
SELECT
id,
name,
board_id,
description,
jql,
position
FROM jira.agile.board_quick_filters
WHERE board_id = '{{ board_id }}' -- required
AND cloud_id = '{{ cloud_id }}' -- required unless ATLASSIAN_CLOUD_ID is set
AND start_at = '{{ start_at }}'
AND max_results = '{{ max_results }}'
;
```
</TabItem>
</Tabs>
