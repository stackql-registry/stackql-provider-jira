Returns counts of the issues and unresolved issues for the project version.&lt;br /&gt;&lt;br /&gt;This operation can be accessed anonymously.&lt;br /&gt;&lt;br /&gt;**&#91;Permissions&#93;(#permissions) required:** *Browse projects* project permission for the project that contains the version.

```sql
SELECT
issues_count,
issues_unresolved_count,
self
FROM jira.projects.version_unresolved_issue_counts
WHERE id = '{{ id }}' -- required
AND cloud_id = '{{ cloud_id }}' -- required unless ATLASSIAN_CLOUD_ID is set
;
```
