Validates a project key and, if the key is invalid or in use, generates a valid random string for the project key.&lt;br /&gt;&lt;br /&gt;**&#91;Permissions&#93;(#permissions) required:** None.

```sql
SELECT
value
FROM jira.projects.valid_project_keys
WHERE cloud_id = '{{ cloud_id }}' -- required unless ATLASSIAN_CLOUD_ID is set
AND key = '{{ key }}'
;
```
