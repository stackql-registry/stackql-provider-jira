<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },

    ]}
>
<TabItem value="get">

Returns a project category.&lt;br /&gt;&lt;br /&gt;**&#91;Permissions&#93;(#permissions) required:** Permission to access Jira.

```sql
SELECT
id,
name,
description,
self
FROM jira.projects.categories
WHERE id = '{{ id }}' -- required
AND cloud_id = '{{ cloud_id }}' -- required unless ATLASSIAN_CLOUD_ID is set
;
```
